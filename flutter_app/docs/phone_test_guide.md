# IronLog Flutter v1.0.0 手机测试指南

## 安装

1. 在手机上开启开发者选项和 USB 调试，并使用数据线连接电脑。
2. 在 PowerShell 执行 `adb devices`，确认设备显示为 `device`。
3. 如果设备已经安装旧的 `com.ironlog.app`，先从旧版导出数据。旧 Kotlin/Room 版与 Flutter/Hive 版不会自动迁移数据。
4. 安装 APK：

   ```powershell
   adb install -r .\app-debug.apk
   adb shell am start -n com.ironlog.app/.MainActivity
   ```

   如果出现签名不一致，使用系统设置卸载旧版后再安装；这会清除应用本地数据。

## 建议测试顺序

### A. 首次启动和品牌

- 应用桌面名称显示为 `IronLog`。
- 启动时显示 IronLog 启动图；启动完成后进入“训练概览”。
- 检查桌面图标是否使用杠铃、上升箭头和 IRONLOG 图形。

### B. 模板和训练记录

1. 进入“训练”，创建两个动作模板，例如卧推和深蹲。
2. 长按拖动排序把深蹲移到卧推前面，退出页面后重新进入确认顺序。
3. 记录一次训练，填写动作、重量、次数和至少两组，标记为完成。
4. 编辑一组，修改重量、RPE 和备注；再删除一组，确认汇总随之变化。
5. 强制停止应用后重新打开，确认训练记录仍存在。

### C. 热力图

- 在概览页确认本周训练次数和完成总量更新。
- 查看前视和后视，点击胸、三角肌、腹肌、股四头肌、背阔肌和臀肌等独立区域。
- 确认热度由已完成训练驱动，未训练日期范围显示空状态。
- 使用日期范围选择器选择没有训练的日期，再确认空状态提示；取消选择后应恢复默认“最近 28 天”。
- 放大或缩小页面，检查人体路径、标签和引线没有被裁切。

### D. 单位和身体数据

- 在设置切换 kg/lb。
- 用 lb 录入重量和体重，保存后切换回 kg，确认换算合理且没有重复换算。
- 在趋势页编辑一条体重记录，确认原记录被更新；删除记录后确认列表刷新。

### E. 导入、导出和分享

- 导出 JSON，确认预览包含模板、训练记录、身体数据、设置和模板顺序。
- 导出 CSV，确认文件可读。
- 修改或清空本机数据后导入 JSON，确认数据整体替换；模拟失败时确认不会留下半套数据。
- 在分享 chooser 中取消分享，确认应用回到原页面且训练数据不受影响。
- 没有可用分享应用时，确认出现可理解的失败/不可用提示，核心记录仍可用。

### F. 通知权限和异常

- 关闭训练提醒或拒绝通知权限，确认仍然可以创建、编辑和保存训练。
- 在没有网络的情况下启动和使用全部核心记录功能。
- 旋转屏幕（若设备允许）或使用分屏/窄屏，确认页面不会崩溃；当前完整横屏矩阵仍需用户设备补充验证。

## 反馈信息

发现问题时请记录：手机型号、Android 版本、是否从旧版升级、操作步骤、预期结果、实际结果和截图。可以使用以下命令导出日志：

```powershell
adb logcat -d -t 300 > ironlog-logcat.txt
```

不要上传包含个人训练数据的 JSON 备份或完整 logcat；分享问题时先删除敏感内容。
