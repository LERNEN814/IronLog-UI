## 4. 偏离规格 / 自行解释之处
1. **列表视图改为进入可编辑详情页**（原 M2 底部只读 Sheet）：`CalendarTabRoute` 的列表模式把点击传给 `SessionDetailRoute`；`HistoryViewModel` 的 Sheet 逻辑仍在但不再从该入口触发（技术债见 §5）。
2. **模板占位组不预写数值**：`onStartTemplate` 只创建条目与占位行（`setType` 来自 `PrefillPlanner`），数值由 `SessionViewModel` 打开该会话时按"上次数据"重算——与 R-6.5"用预填规则而非照抄旧数据"一致，也避免与占位样式冲突。
3. **历史编辑的备注每次按键都写库**：无防抖；单字段写入很轻，但比训练页更频繁。
4. **历史编辑的键盘无 ± 步进按钮**（`onStep = {}`）：M3 的键盘 Sheet 复用于此，步进只为训练页设计。
5. **动作历史入口**：训练详情页点击动作名进入 `ExerciseHistoryRoute`（任务卡未指定入口）。
6. **日历一次加载最近 500 条会话头**（批量查询），超出部分不在月历显示；PRD 未规定上限。
7. **`CalendarViewModel`/`ExerciseHistoryViewModel` 无单元测试**：任务卡的测试要求分别落在纯函数（CalendarModelTest、StrengthTrendTest）上；两个 ViewModel 只有编译与 `@Preview` 保证。
8. **编辑历史不触发休息计时**：`SessionDetailViewModel` 不注入 `RestTimer`（由构造保证），也不会发送 `onSetCompleted`。
9. **未新增表/列/迁移**：schema v1 保持冻结；编辑与历史查询全部使用现有列。

## 5. 已知问题 / 技术债
1. **UI 层无自动化测试**：月历点击、图表绘制、编辑交互仅靠编译 + 4 个 `@Preview` + 真机清单。
2. **`HistoryViewModel` 的详情 Sheet 路径成为死代码**（列表视图已改为导航）；M5 可删除或明确保留给其他入口。
3. **备注逐键写库**（见偏离 3）。
