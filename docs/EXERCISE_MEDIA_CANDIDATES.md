# 外部动作媒体候选清单

状态：仅完成候选来源规划，尚未下载或导入任何外部媒体。

## 候选来源

| 来源 | 适合内容 | 许可证核验 | 当前决定 |
|---|---|---|---|
| Wikimedia Commons | 个别动作图片、解剖示意或开放媒体 | 必须逐文件确认许可证、作者和商用条件 | 候选，不下载 |
| 自制媒体 | 关键动作演示 | 无第三方版权风险 | 推荐长期方案 |
| Material Icons Extended | 通用 UI 图标 | Apache License 2.0 | 已使用 |

## 暂不采用

- 训记、Strong、Hevy 或其他商业 App 的截图、动图和动作素材：来源和再分发权不明确。
- 未明确授权的健身网站图片：不能直接加入 APK。
- 仅允许非商业使用的素材：当前产品未来可能发布，因此暂不作为正式资源。

## 导入前检查

每个候选文件必须补齐：动作 ID、原始 URL、作者、许可证全文或链接、下载日期、文件哈希、是否允许修改、是否允许商用和再分发。完成后先向用户报告，再下载到 `app/src/main/assets/exercises/`。
