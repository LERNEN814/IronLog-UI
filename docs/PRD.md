# PRD — IronLog Phase 1（训练记录）

> 需求编号 `R-x.y` 在任务卡与审计中引用。标注 **[M#]** 的是交付该需求的里程碑。

## 0. 产品原则
1. **训练中不打断**：一只手、出着汗、组间 60 秒内也能完成记录。每个核心操作 ≤ 2 次点击。
2. **数据永不丢**：每次交互立即落库；进程被杀后可以恢复；可以导出。
3. **离线**：Phase 1 不联网，不申请 `INTERNET` 权限。
4. **只做 Android**，minSdk 26，targetSdk 36。

## R-1 动作库 [M1 数据 / M2 界面]
- R-1.1 内置 ≥ 100 个动作（M1 ≥ 60），每个动作有中英文名、类型（力量/有氧/自重/计时）、器械、主动肌/协同肌映射。
- R-1.2 选择动作页：搜索（中文名、英文名、拼音首字母可选不做）；按部位筛选（胸/背/肩/臂/腿/核心/有氧）；最近使用排在前面。
- R-1.3 自定义动作：名称、类型、器械、主动肌（必选 1 个）、协同肌（可多选）。
- R-1.4 支持归档（隐藏）动作，不物理删除（历史记录要保留）。

## R-2 训练记录 [M2]
- R-2.1 主页"开始训练"按钮 → 创建 `IN_PROGRESS` 会话并进入训练页。若已有进行中的会话，按钮变为"继续训练"。
- R-2.2 训练页：顶部显示已用时（mm:ss，基于 `started_at` 实时计算）；动作卡片列表；底部"添加动作"与"结束训练"。
- R-2.3 添加动作后，按 DOMAIN_RULES §3 生成预填组。
- R-2.4 **组行**展示：序号/类型标签 | 上次（灰色小字，如 `60×8`）| 重量 | 次数 | ✓。
  - 预填值以**占位**样式显示（灰色）；用户修改后变为正常颜色。
  - 点 ✓：若字段为空且存在占位值 → 采用占位值；若仍为空 → 抖动提示，不完成。
  - 完成后行背景变色，✓ 高亮；再次点击 ✓ 取消完成。
- R-2.5 **组类型**：点击序号标签弹出菜单：正式 / 热身（显示 `W`）/ 递减（显示 `D`）/ 力竭（显示 `F`）。热身组不参与序号计数（正式组显示 1, 2, 3…）。
- R-2.6 组操作：添加一组（复制上一组的值作为占位）、左滑删除一组、长按条目可以删除整个动作或上下移动。
- R-2.7 **单位**：全局默认单位在设置中；每个组记录 `input_unit`；训练页右上角可快速切换当前显示单位（只改显示，不改存储）。
- R-2.8 RIR 字段默认隐藏，在设置中开启后，组行增加一列 RIR（0–5）。
- R-2.9 **有氧动作**：组行改为 时长（分:秒）| 挡位/坡度/速度（按器械显示）| 距离（可选）| ✓。
  - 爬楼机（`stair_climber`）：时长 + 挡位。
  - 跑步机（`treadmill`）：时长 + 速度 + 坡度 + 距离（可选）。
  - 椭圆机/单车（`elliptical`/`bike`）：时长 + 挡位 + 距离（可选）。
- R-2.10 **结束训练**：弹出 BottomSheet：本次汇总（时长、动作数、正式组数、总容量）；**自我评价 5–10 分**（6 个大按钮，单选，可跳过）；备注（可选）；按钮【完成训练】【继续加练】。
  - 【继续加练】关闭弹窗，会话保持 IN_PROGRESS。
  - 【完成训练】写入 `ended_at`、`rating`、状态 `FINISHED`，回到主页（M5 后跳转到分享预览）。
  - 若所有组都未完成，【完成训练】需二次确认"本次训练没有已完成的组，确定要结束并丢弃吗？"→ 删除该会话。
- R-2.11 已结束的训练可以在历史中重新打开编辑（修改/删除组、改评分），状态不回退为进行中。 [M4]

## R-3 组间休息计时器 [M3]
- R-3.1 完成一组（点 ✓，且该组不是该动作的最后一组，或者是最后一组但会话中后面还有动作——简单起见：**每次完成一组都弹出**）后，底部弹出休息选择条：`30s` `90s` `120s` `150s` `其他` `跳过`。默认高亮上次选择。
- R-3.2 选择后开始倒计时：屏幕底部固定显示倒计时条（圆环/进度条 + 剩余时间 + `-15s` `+15s` `跳过`）。
- R-3.3 时间到：播放提示音 + 震动（遵循系统勿扰/静音）；App 在后台或锁屏时通过通知提醒（高优先级，带声音）。
- R-3.4 App 在后台时，通知栏显示实时倒计时（系统 Chronometer），点击回到训练页。
- R-3.5 进程被杀后重新进入：若 `rest_target_at` 未过期，恢复倒计时；已过期则清除。
- R-3.6 首次使用时引导授予通知权限（Android 13+）和精确闹钟权限（Android 12+，`SCHEDULE_EXACT_ALARM`）；拒绝后降级并在计时条上显示"提醒可能延迟"的提示图标。
- R-3.7 设置页提供"后台提醒不准时？"帮助页：说明电池优化/自启动设置，按厂商给出跳转（能跳转系统电池优化设置页即可，不申请 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`）。
- R-3.8 训练页保持屏幕常亮（设置可关闭）。

## R-4 日历与历史 [M4]
- R-4.1 历史列表：按时间倒序，每项显示日期、时长、动作名摘要（最多 3 个 + "等 N 个"）、评分、部位色点。
- R-4.2 月历视图：自绘（不引入第三方日历库），有训练的日期下方显示最多 4 个部位色点。
  - 部位颜色（`body_region`）：0 胸 `#E53935`，1 背 `#1E88E5`，2 肩 `#FB8C00`，3 臂 `#8E24AA`，4 腿 `#43A047`，5 核心 `#FDD835`，6 有氧 `#00ACC1`。
- R-4.3 点击日期 → 当日训练详情（可以有多个会话）；详情页可编辑（R-2.11）、删除整个训练（二次确认）。
- R-4.4 单个动作历史页：该动作所有记录 + 估算 1RM 曲线（Canvas 自绘简单折线，不引入图表库）。

## R-5 主页与热力图 [M5]
- R-5.1 主页从上到下：开始/继续训练按钮 | 7 日肌肉疲劳热力图（正面/背面人体轮廓）| 本周统计（训练次数、总组数）| 最近 3 次训练卡片。
- R-5.2 热力图数据按 DOMAIN_RULES §5 计算，每次进入主页重新计算（不做后台任务）。
- R-5.3 人体图：M5 先用**简化的几何分区人体图**（Compose Canvas 自绘的圆角矩形/椭圆组合，正面 + 背面），每个肌群一个区域，按分档着色；点击区域显示肌群名和分数。精细解剖 SVG 留待之后。
- R-5.4 结束训练后生成**分享图**：日期、时长、总容量、动作与最佳组、PR 标记、部位色条、App 名。渲染离屏 Composable → Bitmap → 保存到 MediaStore（`Pictures/IronLog`）/ 系统分享。
- R-5.5 PR：按 DOMAIN_RULES §6 判定，在训练页完成组时即时显示 🏆 标识，汇总与分享图中展示。

## R-6 设置、体重、数据安全 [M6]
- R-6.1 设置：默认单位（kg/lb）、距离单位、默认休息时长与 4 个预设值、屏幕常亮、显示 RIR、主题（跟随系统/亮/暗）。
- R-6.2 体重打卡：主页入口，一天一条（覆盖），显示最近 30 天折线。
- R-6.3 导出：SAF 选择位置 → 写入 JSON（DATA_MODEL §6）。导入：选择文件 → 校验版本 → 二次确认 → 覆盖写入。
- R-6.4 Android Auto Backup：`backup_rules.xml` / `data_extraction_rules.xml` 包含数据库与 DataStore。
- R-6.5 训练模板（轻量）：在历史训练详情中"以此为模板开始训练"→ 新会话复制动作列表与预填（使用"上次数据"规则，而非模板中的旧数据）。

## 非功能需求
- N-1 冷启动到主页可交互 < 1.5s（中端机）。
- N-2 训练页任何操作到 UI 更新 < 100ms。
- N-3 深色模式完整适配。
- N-4 所有可点击元素 ≥ 48dp，自定义键盘按键 ≥ 56dp 高。
- N-5 TalkBack：自定义键盘每个键有 contentDescription；组行 ✓ 有状态描述。
- N-6 Release 构建开启 R8；APK < 15 MB。

## 明确不做（Phase 1）
账户/云同步、社交、训练计划生成、AI、饮食、Wear OS、Health Connect、桌面小组件、平板布局、多语言切换 UI（但字符串全部资源化，默认中文）。
