| Room 2.8 旧的 `MigrationTestHelper.createDatabase(name, version)` + Robolectric 报路径错误 | 改用 driver 版 API（`file` + `driver` + `databaseClass`），模板已验证 |

| 本机 `JAVA_HOME` 指向已卸载的 JDK | `scripts/env.sh` 自动定位可用的 JDK 17 |
| Git autocrlf=true 会改写受保护文件的行尾导致哈希校验误报 | 增加 `.gitattributes`（`text=auto eol=lf`）+ 哈希计算归一化行尾 |
