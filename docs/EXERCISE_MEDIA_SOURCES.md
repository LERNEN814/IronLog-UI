# 动作媒体来源登记表

此文件用于用户复核每一张动作图片、动图或视频的来源。没有登记的外部媒体不得进入正式 APK。

当前状态：暂无外部动作媒体。

| 资源文件 | 动作 ID | 来源 URL | 作者 | 许可证 | 商用/再分发确认 | 备注 |
|---|---|---|---|---|---|---|
| 无 | 无 | 无 | 无 | 无 | 不适用 | 当前使用占位图标 |

## 图标依赖

应用使用 AndroidX Compose Material Icons Core / Extended，许可证为 Apache License 2.0，依赖版本由 Compose BOM 管理。该依赖不是动作演示媒体。

## 接入规则

1. 下载前登记来源 URL 和许可证。
2. 下载后保存原始文件名、作者和许可证文本。
3. 每个动作目录放置 `license.txt`。
4. 更新本表后才能把资源加入 APK。
