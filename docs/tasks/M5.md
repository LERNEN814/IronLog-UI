## T5.1 热力图数据装配
- `domain/fatigue/FatigueRepository.kt`（接口）+ `data/repository/FatigueRepositoryImpl.kt`：
  - 查询最近 168 小时内所有已完成组 + 动作肌群映射 + 会话时间 → 组装 `List<FatigueInputSet>` → 调用 `FatigueModel.compute`。
  - `completed_at` 为空时回退到会话 `started_at`。
  - 在 `Dispatchers.Default` 上计算，返回 `Map<String, Int>`（muscleId → score）。
- 测试 `FatigueRepositoryImplTest`（Robolectric）：与 `FatigueModel` 直接调用结果一致（端到端一致性）；窗口外记录被排除；未完成组被排除；`completed_at` 为空时使用会话时间。

## T5.2 人体图与热力图 UI
- `ui/feature/home/MuscleHeatmap.kt`：
  - Compose Canvas 自绘**简化分区人体图**（正面：胸、肩前束、肱二头、前臂、腹、股四头、小腿；背面：上背、背阔肌、下背、肩后束、肱三头、臀、腘绳肌、小腿）。
  - 每个区域是一个 `Path`，几何参数按下方规则由你在 `RegionGeometry.kt` 中定义，按 score 分档着色（DOMAIN_RULES §5.3）。
  - 正面/背面切换（Tab 或左右滑动）；点击区域 → 弹出肌群名 + score + 最近刺激摘要。
  - 顶部一档图例（无/低/中/高/极高）。
- 参数：把每块肌肉的几何定义为 `data class RegionShape(val muscleId: String, val body: Int, val rect: RectF, val cornerRadius: Float)`，坐标用 0..1 的归一化值（绘制时乘以画布尺寸），先全部用**圆角矩形/椭圆**近似；左右对称的肌肉画两块、共用同一个 muscleId，在 `RegionGeometry.kt` 中集中定义。肉眼看得出哪些部位被练到即可，不追求解剖精度。
- 测试：`ui/feature/home/HeatmapColorsTest.kt`——score → 颜色映射的边界值（0/1/24/25/49/50/74/75/100）。

## T5.3 分享长图
- `ui/feature/summary/ShareCard.kt`：离屏 Composable（固定宽度 1080px 的卡片：日期、时长、总容量、动作与最佳组、PR 🏆、部位色条、App 名）。
- 渲染：`ComposeView` + `GraphicsLayer.toImageBitmap()`（Compose 1.7+ API，BOM 2026.09 支持）或 `AndroidView` + `View.draw(Canvas)`。
- 保存到 `MediaStore`（`Pictures/IronLog`，Android 10+ 无需权限，`RELATIVE_PATH` + `IS_PENDING`）；分享用 `FileProvider` + `ACTION_SEND`（`res/xml/file_paths.xml`）。
- 测试（Robolectric 可做）：位图尺寸 = 1080 × 期望高度；文件名格式 `IronLog_YYYY-MM-DD_HHmm.png`。
