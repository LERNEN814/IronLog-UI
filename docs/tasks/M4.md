# M4 — 日历、历史与动作历史

**目标**：日历视图、历史记录详情与编辑、单动作历史与 1RM 曲线。
**前置**：M3 审计通过（M4 只依赖 M2 的数据，但按里程碑顺序推进以避免冲突）。

**完成标准**：`bash scripts/verify.sh` 全绿 + 真机自测。

---

## T4.1 日历数据与纯逻辑
- `domain/calendar/CalendarModel.kt`（纯函数）：
  - `fun monthGrid(year: Int, month: Int, firstDayOfWeek: DayOfWeek): List<LocalDate?>`（含前后补空格）。
  - `fun regionDots(sessions: List<WorkoutSession>, details: Map<String, Set<Int>>): List<Int>`——按 PRD R-4.2 排序（胸/背/肩/臂/腿/核心/有氧），最多返回 4 个。`details` 由 `SessionSummary.bodyRegions` 提供，**按 `started_at` 去重同一天多个会话并取并集**。
- 测试 `CalendarModelTest`：月首/月末补空、闰年 2 月、周日/周一起始、同一天两个会话（胸 + 有氧 → 2 个点）、超过 4 个部位时截断并保证顺序稳定。

## T4.2 月历页面
- `ui/feature/calendar/`：自绘月历（`LazyVerticalGrid` 或 `Column` + `Row`，不用第三方库），顶部年月切换，今天高亮，有训练的日期显示色点。
- 点击日期 → 当日会话列表（可能多个）→ 点击进入 `SessionDetailRoute`。
- 底部导航：把"历史"标签改为进入日历页，日历页底部有"列表视图"切换（对应 M2 的历史列表）。

## T4.3 训练详情与编辑
- `ui/feature/history/SessionDetailViewModel` + `Screen`：
  - 头部：日期、时长、总容量、评分（可修改）、备注（可修改）。
  - 动作列表与所有组（含类型标签）。
  - 编辑：修改组的重量/次数/类型、删除组、添加组、删除动作。
  - 删除整个训练（二次确认）。
  - "以此为模板开始训练"（PRD R-6.5）：创建新会话并复制动作条目，组用"上次数据"预填规则生成。
- 测试 `SessionDetailViewModelTest`：修改后落库、删除训练后列表不再包含它、以模板开始训练生成正确的条目数与预填组。

## T4.4 动作历史与 PR 曲线
- `ui/feature/exercise/ExerciseHistoryViewModel` + `Screen`：该动作每次训练的最佳组、总容量、估算 1RM 折线（Canvas 自绘，标注 PR 点）。
- 纯逻辑 `domain/strength/StrengthTrend.kt`：把组列表整理成 `List<TrendPoint(date, bestE1rmGrams, volumeGrams)>`——只取已完成的力量组，按 `local_date` 分组取最大值。
- 测试 `StrengthTrendTest`：向量 E1–E3 的 1RM 参与、无有效组时跳过该日、按日期升序。

## M4 交接要求
- `docs/handoff/M4.md`，真机自测：
  1. 新增两次训练（不同日期、不同部位）→ 日历色点正确。
  2. 编辑历史训练的重量 → 汇总数字随之变化。
  3. 以历史训练为模板 → 新会话动作一致、组为预填占位。
  4. 动作历史页曲线正确、PR 标记出现在正确日期。
