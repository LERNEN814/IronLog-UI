# M2 — 主页、动作库、训练记录闭环

**目标**：能用 App 完整跑完一次训练（添加动作 → 记录组 → 完成 → 结束评价），并能在主页与历史中看到记录。单位切换、组类型、有氧记录、预填全部可用。

**前置**：M1 审计通过。

**完成标准**：`bash scripts/verify.sh` 全绿；`./gradlew assembleDebug` 产出 APK；用户在真机上完成一次自测（清单见 M2 交接）。

---

## T2.1 导航与主题基座
- 完善 `ui/navigation/`：路由 `HomeRoute`、`ExercisePickerRoute`、`SessionRoute(sessionId)`、`SessionSummaryRoute(sessionId)`、`HistoryRoute`、`SettingsRoute`（M4/M6 的页面先建占位）。
- `ui/theme/`：`Color.kt`（含 PRD R-4.2 的部位色）、`Type.kt`、`Dimens.kt`（触控尺寸常量）、深色模式完整适配。
- 底部导航栏（3 项：主页 / 历史 / 设置），训练页与动作选择页**全屏无底部栏**。

**验收**：`assembleDebug` 成功；`@Preview` 可渲染。

## T2.2 主页（最小版）
- `ui/feature/home/HomeViewModel` + `HomeScreen`：
  - 顶部："开始训练" / "继续训练（已用时 mm:ss）"，点击 → 创建或恢复会话 → 导航到 `SessionRoute`。
  - 本周统计：本周训练次数、正式组总数（`domain/summary` 复用）。
  - 最近 3 次训练卡片（日期、时长、动作名摘要、评分），点击进入历史详情（M4 完整版，此处先跳 `HistoryRoute`）。
  - 热力图位置先放占位卡片（M5 实现）。
- 测试 `HomeViewModelTest`（Turbine + 假 Repository）：无进行中会话时按钮文案为"开始训练"；有进行中会话时为"继续训练"。

## T2.3 动作选择页
- `ui/feature/exercise/ExercisePickerViewModel` + `Screen`：
  - 搜索框（中文名/英文名包含匹配，不区分大小写）。
  - 部位筛选 chips（全部/胸/背/肩/臂/腿/核心/有氧）。
  - 列表项：名称 + 器械 + 主动肌标签 + 最近使用标记。
  - 右上角"+ 新建动作"→ 自定义动作表单（名称、类型、器械、主动肌、协同肌多选）；保存后自动选中该动作。
- 测试 `ExercisePickerViewModelTest`：搜索过滤、部位过滤、自定义动作创建后出现在列表首位。

## T2.4 训练页与组编辑（核心）
- `ui/feature/session/SessionViewModel` + `SessionScreen`：
  - 顶部：已用时（每秒刷新，用 `Clock` + `LaunchedEffect`）、单位切换按钮、屏幕常亮开关（遵循设置）。
  - 动作卡片：动作名 + 部位标签 + 该动作"上次"的摘要（如 `60×8, 60×8, 60×7`）。组行按 R-2.4 渲染。
  - 点击组行的重量/次数格子 → 底部弹出**自定义数字键盘**（`ui/feature/session/KeypadSheet.kt`，纯展示 + 回调，逻辑用 `domain/keypad/Keypad.kt`）。
    - 键盘布局：3×4 数字 + `.` + ⌫ + 大号"完成"；重量模式顶部有 `-2.5 / +2.5`（或 lb 对应步长）按钮。
  - 勾选 ✓ → 立即写库（`is_completed=1`，`completed_at = clock.nowMillis()`）→ 触发休息计时（M3；M2 先留接口 `onSetCompleted()` 空实现 + TODO 注释）。
  - 组类型菜单（R-2.5）、添加一组、删除组、删除动作、动作排序。
  - 有氧动作按 R-2.9 切换字段。
  - "结束训练"→ `ui/feature/session/SummarySheet.kt`：汇总 + 5–10 评分 + 备注 + 【完成训练】/【继续加练】。
- 测试 `SessionViewModelTest`：
  - 添加动作 → 生成预填组（复用 M1 的 `PrefillPlanner` 结果）。
  - 勾选未修改的预填组 → 采用占位值写入。
  - 空组勾选 → 不写入且发出"需要输入"的事件。
  - 切换单位 → 存储的 `weight_g` 不变，UI 文本变化。
  - 结束训练 → 会话 `FINISHED`、`rating` 写入、`ended_at` 非空。
  - 继续加练 → 会话仍为 `IN_PROGRESS`。
  - 全部组未完成时结束 → 发出"确认丢弃"事件，确认后会话被删除。

- 测试：列表排序与摘要拼接逻辑（抽成纯函数 `domain/summary/SessionListFormatter.kt` 并测试）。

## T2.6 设置页（最小版）
- `ui/feature/settings/SettingsViewModel` + `Screen`：单位、距离单位、默认休息时长与预设、屏幕常亮、显示 RIR、主题。（体力重量打卡、导出在 M6。）

## M2 交接要求
- `docs/handoff/M2.md`：包含"真机自测清单"（用户手填），至少：
  1. 添加 3 个动作、共 10 组并全部完成，结束训练并给 8 分 → 主页与历史可见。
  2. lb 模式下输入 `45` → 保存后仍显示 `45`，切到 kg 显示 `20.41`。
  3. 训练中切换到其他 App 再回来 → 数据仍在，已用时正确。
  4. 训练中杀掉 App 再打开 → 自动回到训练页且数据完整。
  5. 有氧：跑步机记录时长 + 速度 + 坡度。
  6. 深色模式与亮色模式各截一张图。
