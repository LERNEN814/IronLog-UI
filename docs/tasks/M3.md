# M3 — 组间休息计时器

**目标**：完成一组后可以选择休息时长并倒计时，前台/后台/锁屏都能可靠提醒，进程被杀可恢复。
**规格**：严格按 `docs/REST_TIMER.md` 实现。**这是 Phase 1 最高风险模块。**

**前置**：M2 审计通过（需要训练页的 `onSetCompleted()` 挂点）。

**完成标准**：`bash scripts/verify.sh` 全绿；用户在真机上完成 REST_TIMER §10 的 5 项验收（写进交接报告）。

---

## T3.1 计时数学与时钟
- `domain/timer/RestTimerMath.kt`（DOMAIN_RULES §7）。
- `core/time/ElapsedClock.kt`：`interface ElapsedClock { fun elapsedRealtime(): Long }` + 生产实现（`SystemClock.elapsedRealtime()`）+ `FakeElapsedClock`（测试）。
- 测试：向量 T1–T6。

## T3.2 权限与通知基础设施
- `platform/timer/ExactAlarmPermission.kt`：`canScheduleExactAlarms()` 封装 + 跳转 Intent + DataStore 记录是否已引导过。
- `platform/timer/RestNotifications.kt`：
  - 渠道 `rest_running`（LOW，无声）、`rest_done`（HIGH，默认音 + 震动）。
  - `buildRunning(targetWallMillis, sessionId)`：`setUsesChronometer(true)` + `setChronometerCountDown(true)` + `setWhen(targetWallMillis)` + `setOngoing(true)` + `setOnlyAlertOnce(true)` + `contentIntent` 指向 `MainActivity`（带 `sessionId` 参数）。
  - `buildFinished(sessionId)`。
  - `showRunning()/cancelRunning()/showFinished()`。
- `platform/timer/RestAlarmScheduler.kt`：
  - `interface RestAlarmScheduler { fun schedule(targetElapsed: Long): Boolean; fun cancel() }`（返回是否精确）。
  - `AlarmRestAlarmScheduler`：按 REST_TIMER §4 的策略选择 `setExactAndAllowWhileIdle` 或 `setAndAllowWhileIdle`。
  - 测试用 `FakeRestAlarmScheduler`（记录调用），放在 `src/test`。
- `platform/timer/RestAlarmReceiver.kt`：`onReceive` → 调用 `RestTimerRepository.onAlarmFired()`。
- Manifest 权限与 receiver 注册（REST_TIMER §5）。

## T3.3 RestTimerRepository
- 按 REST_TIMER §4/§6/§7 实现：`StateFlow<RestTimerUiModel?>`（含 `remainingMillis`、`totalMillis`、`isExact`、`isRunning`）、`start/adjust/skip/finish/onAlarmFired/restore`。
- 前后台判定：`ProcessLifecycleOwner`；前台完成 → 走 `TimerEvent.Finished` 事件流；后台完成 → 发通知。
- 写库 `rest_target_at`（通过 `WorkoutRepository`）。

**测试**（Robolectric + Fake）：TR1–TR5 + 通知渠道创建不抛异常 + 前台/后台分支（用假的 `isAppInForeground` 供应商）。

## T3.4 UI 集成
- `ui/feature/timer/RestTimerBar.kt`：训练页底部固定条，显示圆环进度 + 剩余时间 + `-15s` `+15s` `跳过`；不精确时显示提示图标（点击 → 权限引导对话框）。
- `ui/feature/session/RestPickerSheet.kt`：完成组后弹出的时长选择（预设 + 其他）。选择 → `repository.start()`。
- 训练页 App 内提示音 + 震动：`RingtoneManager` 默认通知音，`Vibrator` 300ms。
- 权限引导流程（REST_TIMER §8）。
- 设置页加"后台提醒不准时？"帮助项（R-3.7）。
- 屏幕常亮（`FLAG_KEEP_SCREEN_ON`，跟随设置）。

## T3.5 恢复与边界
- App 启动/回到前台时 `restore()`（REST_TIMER §7）。
- 边界：倒计时中结束训练 → 自动 `finish()`；倒计时中删除正在休息的组 → 不取消计时（保持简单）；连续完成两组 → 重新 start 覆盖旧计时。
- 测试：这些边界各一条 Robolectric 测试。
